# Development and Evolution of a Deep Learning Classification Model for Detecting Hyperkinetic Speech Patterns

## Overview
This project, conducted at **Ural Federal University, Russia**, develops a Convolutional Neural Network (CNN) model to detect hyperkinetic speech patterns. Built with **TensorFlow** and **Keras**, it uses a dataset of healthy and disordered voice recordings to train and validate the model. The project was presented to a jury with a business model, showcasing AI's potential in healthcare.

## Objectives
- Build a CNN to classify hyperkinetic speech patterns.
- Train and validate using a dataset of voice recordings.
- Demonstrate AI applications in healthcare.

## Technologies
- **Python**  
- **TensorFlow**  
- **Keras**  
- **Dataset**: Voice recordings (healthy and disordered)

## Methodology
1. **Data Collection**: Gathered labeled voice recordings.
2. **Preprocessing**: Converted audio into CNN-compatible features (e.g., spectrograms).
3. **Model Design**: Created a CNN with TensorFlow and Keras.
4. **Training**: Optimized the model on the dataset.
5. **Validation**: Tested performance on a validation set.
6. **Presentation**: Showcased results and business model to a jury.

## Results
- Successfully classified hyperkinetic speech patterns.
- Promising accuracy (specific metrics pending).
- Positive jury feedback on technical and business aspects.

## Applications
- Early detection of speech disorders.
- Telemedicine diagnostics.
- Support for speech therapy.
